# profile-app-practice

## 概要
COACHTECH 教材 Tutorial 9-1-8「Laravel基礎ハンズオン」で作成した成果物です。
- 山田太郎さんのプロフィール（名前・年齢・趣味一覧）を作成しブラウザで表示した。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Blade テンプレート

## 学んだこと
- Laravelでルーティング➡コントローラー➡ビューの流れで作成することができた。
- return view() でビュー名や変数名を指定する際、実際のファイル名や変数名と一致させる必要があることを学んだ
- コントローラーのメソッド内で配列（$data）としてプロフィール情報を定義し、ビューへ渡す書き方を習得した
